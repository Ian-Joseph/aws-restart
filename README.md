# AWS re/Start – Python Exercises

This repository contains Python scripts, datasets, and practice exercises developed during the **AWS re/Start** program.  
It includes examples covering programming fundamentals, file handling, loops, conditionals, and string manipulation.

## 🚀 Getting Started

### Prerequisites
- Python 3.x installed on your system
- Text editor or IDE (e.g. VSCode, PyCharm, Cloud9)
- Git for cloning the repo

### Running the Scripts
Clone this repository:

```bash
git clone https://github.com/Ian-Joseph/aws-restart.git
cd aws-restart
````

Run any script, for example:

```bash
python3 hello-world.py
```
